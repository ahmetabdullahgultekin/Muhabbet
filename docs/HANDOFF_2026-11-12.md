## 5. Environment facts learned this session (cloud container)

- **Docker works here**: `dockerd &` as root; Testcontainers suites then run. Baseline on `dev` + docs
  with Docker: **0 failures** (including #269, which now passes). Measure again; do not quote counts.
- **Maven Central answers 429 through the proxy** under Gradle's parallel fetches → user-level init
  script `~/.gradle/init.d/central-mirror.gradle` routing through
  `https://maven-central.storage-download.googleapis.com/maven2/` (spec'd for the SessionStart hook).
- **Android SDK** is not preinstalled: cmdline-tools + `platforms;android-36`, `platforms;android-35`,
  `build-tools;36.0.0` into `/opt/android-sdk`; `assembleDebug` needs the CI dummy
  `google-services.json` (gitignored; heredoc in `.github/workflows/mobile-ci.yml`).
- **iOS cannot be built here** (no macOS). Device behaviour is owner-only (emulator-5554 on the Windows PC).
- **Detached HEAD trap (cost: five unpushed commits):** an agent ran `git checkout origin/dev` in the
  main checkout; every later commit landed on a detached HEAD and `git push origin <branch>` pushed
  nothing. **Verify every push with `git ls-remote origin refs/heads/<branch>`**, and never let a
  read-only agent check out a ref in the main working tree — use `git show`/`git diff` instead.
- Agent concurrency in workflows is ~2 on this 4-CPU host; large workflows run as queues.
